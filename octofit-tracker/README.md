# OctoFit Tracker (project scaffold)

This folder contains the OctoFit Tracker app scaffold.

Structure
```
octofit-tracker/
├── backend/
│   ├── venv/         # virtualenv (placeholder)
│   ├── octofit_tracker/  # python package
│   └── requirements.txt
└── frontend/
```

Quick setup

```bash
python3 -m venv octofit-tracker/backend/venv
source octofit-tracker/backend/venv/bin/activate
pip install -r octofit-tracker/backend/requirements.txt
```

Notes
- Create the Django project inside `octofit-tracker/backend/` when ready.
- Follow the attached project instructions for MongoDB and ports.
